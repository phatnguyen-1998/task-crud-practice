# task-crud-practice

## 概要

COACHTECH 教材 Tutorial 11-2「タスク管理APIのCRUD実装」で作成した成果物です。
タスク管理APIを実装し、Postmanで各操作のステータスコードとレスポンス

## 使用技術

- PHP 8.x
- Laravel 10.x
- REST API（CRUD）
- API Resources、FormRequest（バリデーション）

## 学んだこと

- TaskControllerを作成する
- CRUDメソッドを実装する
- ルーティングを設定する
- Postmanで動作確認する

## 動作確認

GET /api/tasks
POST /api/tasks
GET /api/tasks/{id}
PUT /api/tasks/{id}
DELETE /api/tasks/{id}
